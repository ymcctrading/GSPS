# GSPS Memory Bank — Gann, cycle theory & the Hermetic lens

This folder is the durable research memory the project owner asked for: every Gann book, the Observation of Cycles folder, and Hauck's *Emerald Tablet*, read page by page and **synthesised in our own words**.
- No source book or verbatim text is stored here; this repository is public.
- The source PDFs stay in the project owner's Google Drive.

**Start with** [`GANN_CYCLES_HERMETIC_MASTER_REPORT.md`](GANN_CYCLES_HERMETIC_MASTER_REPORT.md). It holds:
- Gann's methodology by technique
- Dewey's full 18-criterion cycle checklist
- the Tomes/Dewey harmonic lattice and its bridge to Gann's numbers
- the Hermetic lens
- where GSPS aligns
- the open gaps, conflicts and documentation corrections, all owner decisions

A PDF copy of the report sits beside it.

**Then go to** `sources/` for per-source detail. Each note has:
- a metadata table (tier, copyright, read status)
- a synthesis with page or chapter references
- a GSPS cross-reference
- the three-question (Gann / Dewey / Hermetic) notes

Read these alongside `AGENTS.md` and `docs/GANN_HISTORICAL_SOURCES.md`, which remain the governing documents.

**Keeping it current:** when a new source is read, add a `sources/` note in the same format and update the report's Part V and Part VI.
