# Cycle-science rules (W039–W045) checked against GSPS cycle code

Sources were read only from `/mnt/project-files/literature-reading-output/works/W039`–`W045` (summary, detailed-notes, visuals, visuals-reinspection) and `collection-synthesis.md` §3. Code was read read-only at `/home/claude/GSPS` (HEAD `06d1124`). Page numbers are the PDF page numbers the reading notes use. W039 figure pages come from `W039/visuals-reinspection.md`.

Authors: Dewey = Edward R. Dewey (W039 1967, W040 1965). Halberg = F. Halberg et al. (W041, 2003). Tomes = Ray Tomes (W042 c.2004, W043 2005, W044 2005, W045 1990/2005).

Each rule is stated in our own words. "Reader assessment" marks a point the reading notes make about a source, not a claim by the source's author.

## C. Gaps worth acting on first (inference from the table)

1. **The cycle code has no null-model test fixture.** No test checks that `detectSpectralCycle` stays inactive on white noise or a random walk (CYC-02, CYC-28). This is the Yule–Slutsky and red-noise case.
2. **Selection leakage in `spectralCycle.ts`.** The hold-out is gated on full-window `active` (CYC-08). The cosinor p-value is post-selection (CYC-32/33).
3. **The pivot-anchored time windows have no base rate** (`timeCycles()`, `yearCycleConvergence`, `macroCycle`, `decadeCycle`). This is Dewey's recurrent-event rule (CYC-24, CYC-51). Only the fixed calendar (W1/W3) has been tested, and only on 2019–2025.
4. **Exact-period assumptions** conflict with Benner (CYC-09), Tomes' average-vs-specific distinction (CYC-43) and Halberg's "circa" (CYC-34/40).
5. **Not implemented anywhere:** Dewey #5 (phase resumption), #8 (multi-cycle interior hold-out) and #9 (wave shape), plus Halberg's acrophase/MESOR CIs and gliding spectra.
